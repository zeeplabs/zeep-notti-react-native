# react-native-nuntis

Official React Native SDK for Nuntis push notifications (FCM + APNS)

## Installation


```sh
npm install react-native-nuntis
```


## Usage


```js
import { multiply } from 'react-native-nuntis';

// ...

const result = multiply(3, 7);
```
